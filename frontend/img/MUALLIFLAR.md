# Suratlar va mualliflar (MUALLIFLAR)

Suratlar Pexels (https://www.pexels.com/license/) va Pixabay saytlaridan olingan (bepul litsenziya). Ular **namunaviy (illyustrativ)** bo'lib, aynan shu mehmonxonani aks ettirmaydi. Hajmi 1400 px gacha kichraytirilgan.

## Papkalar tuzilishi (frontend/img/)

| Papka | Ichida nima bor |
|---|---|
| `bino/` | Mehmonxona binosi: asosiy surat, kechki ko'rinish, bosh fasad |
| `lobbi/` | Lobby va resepshn |
| `yolak/` | Qavat yo'laklari |
| `restoran/` | Restoran, bufet, nonushta, oshxona |
| `zallar/` | Konferensiya va banket zallari |
| `hovli/` | Yashil hudud, hovli, spa |
| `xiyobon/` | Atrofdagi xiyobon va park |
| `avtoturargoh/` | Yopiq avtoturargoh |
| `kutib-olish/` | Kutib olish xizmati (1–5 bosqich) |
| `xonalar/` | Xona turlari: yakka, ikki kishilik, oilaviy, lyuks... |
| `hammom/` | Dush va hammomlar |
| `balkon/` | Balkon va balkondan ko'rinish |
